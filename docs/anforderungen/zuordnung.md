# Zuordnung der Quellen zu den Anforderungen

[Zum Quellenregister](quellen.md) · [Zur Gesamtspezifikation](README.md)

Die Herkunft jeder Alt-ID ergibt sich aus der jeweiligen Datei. Eine Regel kann mehrere unabhängige Pflichten enthalten. Bei übernommenen Detailregeln erschließt der Quellenlink auch die ursprünglichen Begründungen und technischen Beispiele. Eine begründete Ablösung ist ausdrücklich gekennzeichnet.
